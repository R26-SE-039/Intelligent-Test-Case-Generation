# Page 1 – Projects Page

**URL:** `/projects`
**This is the first page the user sees.**

---

## Simple Speech for Viva

> "This is the Projects page. It is the first page that opens when the user runs the application.
>
> Each project is a separate workspace. For example, one project can be for an e-commerce website, and another project can be for a banking website. Each project has its own user stories, its own Gherkin scenarios, and its own test results. They do not mix.
>
> On this page, the user can do three things:
>
> 1. **Create a new project** – by clicking the *New Project* button. A small popup opens, and the user types a project name and an optional description.
> 2. **Open an existing project** – by clicking the *Open* button on any project card. This takes the user to the dashboard of that project.
> 3. **Delete a project** – by clicking the trash icon. The system asks for confirmation before deleting.
>
> For each project, we display the number of user stories inside it and the date when it was created.
>
> If there are no projects yet, the page shows an empty state with a button to create the first project."

---

## Key points to mention
- Multi-project support – isolated workspaces
- Data is stored in PostgreSQL backend
- User can switch between projects anytime
